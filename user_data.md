# User Data
Saffan Technology does not collect any data from the user. User is in sole control of their personal data.

'Notes to BCS' is not an internet based app and you do not need internet to use it. All the data are saved locally inside the user's device so that the user can be the only one who controls his/her data. To delete that user can remove the notes inside the app or clear cache memory or delete backup file or uninstall the app to remove the data completely from user's device.
