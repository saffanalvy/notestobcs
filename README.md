# Notes to BCS
A sophisticated note taking app for BCS students of Bangladesh.

In Notes to BCS app, based on different Subject categories you can create new Notes. Each note can contain up to 5 attachment files. You can anytime edit or delete the notes or the attachment files. You can export your note in PDF to print or share. There is a reading mode where you can read your notes like a book in full screen. There is also a quote section for motivating the BCS students.
